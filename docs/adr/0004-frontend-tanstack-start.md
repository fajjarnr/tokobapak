# Frontend Buang Next.js 15 Ganti TanStack Start + Router

Konteks: `frontend/web` sekarang Next.js 15 App Router + React 19 + `@tanstack/react-query 5.90` + `next-auth` + ISR (`revalidate=60`). Benchmark global (Vercel Commerce, Tokopedia, Shopee) tetap di Next/Nuxt. Kami memutuskan buang Next.js total ganti TanStack Start + TanStack Router + TanStack Query dengan BFF JWT (`auth-service` Go + `golang-jwt/jwt`, HttpOnly cookie + CSRF, Token Relay server-side) dan caching `staleTime 60s` listing/search vs `staleTime 0` cart/checkout via `HydrationBoundary` prefetch.

Keputusan ini hard to reverse karena rewrite `app/` → `src/routes/`, hilangnya `next/image/font/config`, `next-auth` → auth custom, Dockerfile `next build` → `Vite build`, dan Playwright `next dev` → `vite dev`; estimasi 2–3 minggu. Surprising karena menolak pola Next.js Commerce yang direkomendasikan Context7 `/vercel/commerce` dan `/vercel/next.js`. Trade-off: lepas dari Next.js lock-in dan unifikasi data fetching di TanStack Query vs kehilangan kematangan ISR, next-auth ecosystem, dan risiko TanStack Start <1.0 untuk marketplace; mitigasi dengan BFF sesuai PayU `CONTEXT.md` (Browser Session vs Access Token) dan freeze MVP 1 bulan sebelum pertimbangkan balik ke Next.js.
